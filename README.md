# Remind_me_later_api

## Overview
This API stores reminders with date, time, message, and notification method (SMS/email) as specified in the assignment requirements.

## Features

- Stores reminders in SQLite database
- Validates input data
- RESTful endpoint for creating reminders
- Simple error handling

## Setup

1. Clone this repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   npm start
   ```

## Technologies Used

- Node.js (JavaScript runtime)
- Express (web framework)
- SQLite (database)
